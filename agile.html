Agile Projects

Semester 1 Class 2026

What the class was about

ITPM5.240 Agile Projects taught me how project management principles, governance, and risk management are applied when developing software, and how project management fits within agile development methodologies. In a group of three, I planned and controlled a hypothetical e-commerce website project across three iterations, with everything managed in a shared GitHub repository. Each iteration combined group planning documents (meeting reports, a stakeholder register, personas, a Gantt chart, a resource requirement list, and a risk register) with hands-on work such as user testing, GitHub boards, merging code, and publishing the site. I also wrote a group progress report and completed an online quiz at the end of each iteration, and the project finished with a final handover in Week 14.

What I learnt

I learned how to run a project in iterations, reviewing and improving at each stage rather than planning everything up front. I learned to identify stakeholders and assign roles, and to create personas so the website was designed around real user needs. I also learned how to plan with a Gantt chart, work out resource requirements and costs, and track and assign tasks using GitHub boards. On the governance side, I learned how to record and manage risks by describing likelihood, severity, and a clear resolution plan, and how to run user acceptance testing and act on the results. Working in GitHub taught me version control in practice, including documenting in Markdown, pushing files, resolving issues, merging the work of three people, and publishing a static site with GitHub Pages. Writing the progress reports also taught me to reflect honestly on what was working, what wasn't, and what the group needed to improve.

What I achieved

Across the three iterations, my group and I produced meeting reports, a stakeholder register, three personas, a Gantt chart, a resource requirement list, a risk register, and user acceptance test results, all documented in the GitHub repository's readme. In Iteration 3, we merged the Home, Products, and Orders pages from each team member, checked the integration, and published a working static website through GitHub Pages. I submitted a progress report for each iteration and completed all three online quizzes, then helped hand over the final project as a group.

Reflections

This course showed me that project management is as much about communication and process as it is about technology. Following three iterations, I saw how regular meetings, clear roles, and honest reviews keep a team on track, and how tools like GitHub make it possible for three people to build one product together. I found coordinating merges and keeping everyone's contributions equal and visible challenging, so I'd set up our boards and task assignments earlier and check in more often. I'd also like to build more confidence with Git workflows and keep practising writing clear, concise documentation. Overall, I now understand how planning, risk management, and teamwork combine to deliver a working product, which will help me in future project or team roles.
